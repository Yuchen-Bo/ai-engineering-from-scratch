Matrices Are Transformations

矩阵会改变向量

A matrix transforms one vector into another. It can rotate, scale, stretch, or project. 也就是说，矩阵不是一堆数字而已；它描述了一种“空间怎么被移动和拉伸”的规则。

核心直觉

当矩阵 A 乘以向量 x 时，结果是一个新向量 y。 这个过程可以理解为：把原来的向量放进一个变换机器里，输出变换后的方向和长度。

A x = y
matrix * input vector = transformed vector

常见变换

Scale

把向量整体变长或变短，例如所有坐标乘以 2。

Stretch

只沿某个方向拉伸，例如 x 方向变宽，y 方向不变。

Rotate / Project

旋转方向，或把向量压到某条线、某个平面上。

例子

这个矩阵会把向量的 x 坐标放大 2 倍，y 坐标保持不变：

A = [[2, 0], [0, 1]]
x = [2, 1]
A x = [4, 1]

图示

输入向量 x 变换后向量 A x

如果你想象整个坐标网格都被矩阵拉伸，那么向量只是跟着网格一起移动。 这就是把矩阵看成 transformation 的核心直觉。

在 AI 里的直觉： 神经网络的一层经常可以看作一次矩阵变换：输入向量经过权重矩阵后， 被旋转、拉伸、压缩到一个更适合解决任务的新表示空间。

In AI, matrices are the model: neural network weights are matrices that transform input into output; attention scores are matrices that decide what to focus on; embeddings are matrices that map words, tokens, or items into vectors.

所以理解矩阵，不只是为了会算 A x。更重要的是理解： 模型如何把原始输入一步步变成更有用的表示，再变成最终预测。
