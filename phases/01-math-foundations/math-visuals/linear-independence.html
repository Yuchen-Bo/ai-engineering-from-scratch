Linear Independence

线性无关：不是重复的方向

Linear independence means each vector contributes a genuinely new direction. 如果一个向量不能由其他向量缩放、相加得到，它就提供了新的信息。

核心直觉

在二维里，两个向量只要不在同一条直线上，它们就是线性无关。 因为其中一个向量无法只靠拉长、缩短另一个向量得到。

c1*v1 + c2*v2 + ... + cn*vn = 0
only solution: c1 = c2 = ... = cn = 0

两个向量的判断

不平行

两个方向不同，能张成一个平面，线性无关。

平行

一个只是另一个的倍数，没有新方向，线性相关。

零向量

零向量没有方向，一旦出现通常会让集合线性相关。

例子

[1, 0] and [0, 1] are independent
[1, 2] and [2, 4] are dependent
because [2, 4] = 2 * [1, 2]

图示

第一个向量 新的方向 重复方向

线性无关的向量像是在给坐标系统增加新的自由度。 线性相关的向量则只是重复已有方向，信息量没有增加。

Why it matters for AI: your feature matrix should have linearly independent columns. If two features are perfectly correlated, they are linearly dependent, so the model cannot clearly distinguish their effects. In regression, this causes multicollinearity: the weight estimates become unstable, and small input changes can produce large, unreliable output swings.

换句话说，如果两个特征几乎在讲同一件事，模型就很难判断到底应该把权重分给谁。 例如 house_size_m2 和 house_size_ft2 本质上只是单位不同， 它们会让回归模型的权重变得难解释，也更容易对数据里的小变化过度敏感。
